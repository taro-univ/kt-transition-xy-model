# 2D XY モデルの表現学習

## 概要

本プロジェクトは、物理情報を取り込んだ表現学習が
2D XY モデルの相構造をより適切に捉えられるかを検証する。

主な知見：

- ヘリシティ認識コントラスト学習は、明確な三相構造を明らかにする。
- クラスター優位性は温度に沿って一貫してシフトする。
- 潜在空間の感度は推定臨界温度付近でピークを持つ。

これらの結果は、ドメイン知識の組み込みが教師なし学習における
構造的忠実度を向上させることを示唆する。
対称性破れを伴う転移と異なり、KT 転移は単純な二相構造を持たないため、
表現学習にとって難しいベンチマークとなっている。

本プロジェクトは、目的関数の設計・潜在空間幾何の解析・
再現可能な評価パイプラインを重視している。

---

## なぜ重要か

本実験は、ドメイン固有のシグナルを表現学習に組み込むことで、
構造的解釈可能性がどのように向上するかを示す。

このアプローチは以下に一般化できる：
- 科学的機械学習
- 構造化データの表現
- 物理情報 AI システム

本研究は相検出を分類問題ではなく表現学習問題として再定式化する。

---

## 1. 問題設定

### 背景

2D XY モデルは Kosterlitz–Thouless（KT）転移を示す。
これは自発的対称性破れや単純な二相構造を伴わないトポロジカル相転移である。

系は以下の振る舞いを示す：

- 低温の準長距離秩序相
- 高温の無秩序相
- ボルテックス解離によって駆動される非自明な中間領域

これにより、標準的な二値分類での相同定は非自明となる。

---

### 動機

多くの機械学習研究は相検出を二クラス問題（秩序 vs 無秩序）として定式化する。
しかしそのようなアプローチは：

- 人工的な二相解釈を押し付ける可能性がある
- 中間構造を見落とす可能性がある
- 潜在空間で転移領域を崩壊させる可能性がある

本研究の目的は異なる。

相を分類するのではなく、以下を目指す：

> 温度に沿ったシステムの固有の構造組織を忠実にエンコードする潜在表現を学習する。

---

### リサーチクエスチョン

表現学習は以下を実現できるか：

1. 低温・高温領域を分離できるか？
2. 連続的な中間構造を明らかにできるか？
3. 潜在次元を物理的に意味のある観測量に整合させられるか？

---

### アプローチ

4 つの教師なし手法を比較する：

- Autoencoder（AE）
- Variational Autoencoder（VAE）
- Contrastive Learning
- **Helicity-Contrastive Learning（提案手法）**

以下の観点で表現を評価する：

- UMAP 幾何構造
- 温度依存クラスタリング
- 物理量との相関

中心的な問いは、ヘリシティ認識学習が潜在空間の構造的忠実度を
向上させるかどうかである。

## 2. UMAP 比較

### 概要
モデル間の潜在空間の幾何構造を定性的に比較するため、
UMAP を用いて各表現を 2 次元に射影する。

公平な比較のため：
- すべてのモデルに同一の UMAP ハイパーパラメータを使用する。
- 固定乱数シードにより再現性を保証する。
- 可視化の一貫性のため最大 3000 サンプルを使用する。

色は温度 $T$ を示す。

この可視化により以下を確認できる：
- 低温・高温領域が明確に分離されているか
- 中間領域が出現しているか
- 提案するヘリシティ認識モデルが構造的組織の改善を示しているか

```python
# === UMAP visualization cell (AE / VAE / Contrastive / Helicity-Contrastive) ===
# Assumes you run from: notebooks/ (so ../results/notebook_data exists)

from pathlib import Path
import numpy as np
import matplotlib.pyplot as plt

# --- Config ---
DATA_DIR = Path("results/notebook_data")

files = {
    "AE (baseline)": DATA_DIR / "ae_latent.npz",
    "VAE (baseline)": DATA_DIR / "vae_latent.npz",
    "Contrastive (baseline)": DATA_DIR / "contrastive_latent_small.npz",
    "Helicity-Contrastive (proposed)": DATA_DIR / "helicity_contrastive_latent_small.npz",
}

SEED = 42
N_NEIGHBORS = 30
MIN_DIST = 0.10
N_SAMPLES_MAX = 3000
POINT_SIZE = 6
ALPHA = 0.9

# --- Import UMAP (install message if missing) ---
try:
    import umap
except ImportError as e:
    raise ImportError(
        "UMAP is not installed. Run one of the following in your environment:\n"
        "  pip install umap-learn\n"
        "or (conda)\n"
        "  conda install -c conda-forge umap-learn"
    ) from e


def load_latent(npz_path: Path, n_max: int, seed: int):
    d = np.load(npz_path)
    if "z" not in d or "T" not in d:
        raise KeyError(f"{npz_path.name} must contain 'z' and 'T'. keys={list(d.files)}")

    z = np.asarray(d["z"])
    T = np.asarray(d["T"]).reshape(-1)

    if z.shape[0] != T.shape[0]:
        raise ValueError(f"Length mismatch in {npz_path.name}: z={z.shape}, T={T.shape}")

    # Subsample if needed (deterministic)
    N = z.shape[0]
    if N > n_max:
        rs = np.random.RandomState(seed)
        idx = rs.choice(N, size=n_max, replace=False)
        z = z[idx]
        T = T[idx]

    return z, T


def umap_2d(z, seed, n_neighbors, min_dist):
    reducer = umap.UMAP(
        n_components=2,
        n_neighbors=n_neighbors,
        min_dist=min_dist,
        metric="euclidean",
        random_state=seed,
    )
    return reducer.fit_transform(z)


# --- Load all data first (so failures show early) ---
loaded = {}
for name, fp in files.items():
    if not fp.exists():
        raise FileNotFoundError(f"Missing file: {fp}")
    z, T = load_latent(fp, n_max=N_SAMPLES_MAX, seed=SEED)
    loaded[name] = (z, T)
    print(f"[OK] {name:28s} | z={z.shape} dtype={z.dtype} | T={T.shape} dtype={T.dtype}")

# --- Compute UMAP for each model ---
embeddings = {}
for name, (z, T) in loaded.items():
    print(f"[INFO] UMAP fitting: {name}")
    xy = umap_2d(z, seed=SEED, n_neighbors=N_NEIGHBORS, min_dist=MIN_DIST)
    embeddings[name] = (xy, T)

# --- Plot (2x2) ---
fig, axes = plt.subplots(2, 2, figsize=(11, 9), constrained_layout=True)

names = list(files.keys())
vmin = min(np.min(embeddings[n][1]) for n in names)
vmax = max(np.max(embeddings[n][1]) for n in names)

for ax, name in zip(axes.ravel(), names):
    xy, T = embeddings[name]
    sc = ax.scatter(
        xy[:, 0], xy[:, 1],
        c=T,
        s=POINT_SIZE,
        alpha=ALPHA,
        vmin=vmin, vmax=vmax,
    )
    ax.set_title(f"{name}\nUMAP (n_neighbors={N_NEIGHBORS}, min_dist={MIN_DIST})")
    ax.set_xticks([])
    ax.set_yticks([])
    for spine in ax.spines.values():
        spine.set_visible(False)

    if "proposed" in name:
        for spine in ax.spines.values():
            spine.set_visible(True)
            spine.set_linewidth(2.5)

# --- Shared colorbar (Temperature) ---
fig.subplots_adjust(right=0.86)
cbar = fig.colorbar(sc, ax=axes, location="right", shrink=0.8)
cbar.set_label("Temperature T")

out_path = DATA_DIR / "umap_compare_4models.png"
plt.savefig(out_path, dpi=300)
print(f"[INFO] Saved figure: {out_path}")

plt.show()
```

## 3. クラスター構造 vs 温度

UMAP 可視化に基づき、元の潜在空間で **K-means クラスタリング（k = 3）** を行う。

k = 3 の選択は以下に基づく：

- 2D XY モデルで期待される三領域の物理的予測
  （低温・中間（臨界）・高温相）
- ヘリシティ認識埋め込みで観察された三構造分離

クラスタリングは射影アーティファクトを避けるため、
UMAP 空間ではなく潜在空間で直接行う。

各温度 $T$ に対してクラスター確率
$$P_T(k)$$
を計算する。これはクラスター $k$ に割り当てられたサンプルの割合を表す。

$P_T(k)$ の明確な優位シフトは、
異なる構造領域の出現を示す。

![クラスター確率 vs T](results/notebook_data/4model_Cluster_prob_vs_T.png)

## 4. 潜在表現 vs 温度

軽量で再現可能なノートブック構造を維持するため、

この設計は以下を分離する：

- コア解析ロジック（スクリプト）
- 可視化と比較（ノートブック）

ノートブックは各モデルのスクリプトを実行し、
生成された図を並べて比較する。

- ノートブックは可視化の前に生成の成功を検証する。

このモジュール構造により以下が保証される：
- 再現性
- 明確な実験分離
- クリーンなパイプライン設計

>

> - リポジトリサイズの制約
> - 統計的信頼性
> - 視覚的結果の再現性


## 5. 物理量との相関

物理的整合性を評価するため、以下との Spearman 相関に基づいて
上位ランクの潜在次元を選択する：

- Y（ヘリシティ関連観測量）
- nv（ボルテックス密度）

ランキングはローカルでフルデータセットを使って計算した。
リポジトリ効率のため、結果 CSV ファイルのみを含む。

ノートブックは：

1. 事前計算済み CSV から上位 k 次元を抽出
2. スタンドアロンの可視化スクリプトを呼び出す
3. 生成された図を読み込んで比較する

### 設計の意図

このモジュール構造は：

- 統計計算と可視化を分離する
- 再現性を保証する
- リポジトリサイズの制約を維持する
- 統計的に信頼できる相関推定を保つ

これはスケーラビリティと再現性の間の実践的なエンジニアリングトレードオフを反映している。

## 解釈

**重要な知見：** ヘリシティ認識目的関数は、AE/VAE やベースラインのコントラスト学習とは異なり、
（i）温度に沿って滑らかに整理され、（ii）物理的に意味のある観測量（Y, nv）と強く整合する
潜在次元を生成する。


### 構造エンコーディング品質

- **AE / VAE**
  - 温度依存性が弱いか不規則。
  - 単調な転移構造が見られない。
  - 潜在空間が相情報を一貫してエンコードしない。

- **Contrastive（ベースライン）**
  - 部分的な構造が出現する。
  - 転移挙動は混在したまま。
  - 物理量との整合が限定的。

- **Helicity-Contrastive（提案手法）**
  - 温度に沿った滑らかで単調な潜在変化。
  - 明確な領域分離（低温 / 中間 / 高温）。
  - 安定した転移領域の挙動。

### 物理量との相関

フルデータセットの Spearman 相関を用いると：

- 特定の潜在次元が以下と強く整合する：
  - Y（ヘリシティ関連指標）
  - nv（ボルテックス密度）

上位ランクの潜在座標は以下を示す：

- 明確な温度トレンド
- 推定転移点付近での変曲点
- 相内分散の低減

### 表現の洞察

改善は単なるクラスタリングの向上ではない。

提案モデルは：

- 潜在軸を物理的に意味のある方向に整合させる
- 潜在幾何に相構造を滑らかにエンコードする
- 温度に渡る転移エンコーディングを安定化する

これはヘリシティ情報の組み込みが、
表現学習を物理的に解釈可能な構造に向けて正則化することを示唆する。

### エンジニアリングの観点

本実験が示すもの：

- 目的関数の設計が潜在幾何に影響する。
- ドメイン知識が表現の解きほぐしを導ける。
- 構造化評価パイプラインが解釈可能性を向上させる。

このアプローチは物理学を超え、
潜在変数が現実世界の意味論と整合する必要があるあらゆる領域に一般化できる。

## 6. 転移感度（勾配解析）

視覚的な観察から転移領域付近での構造再編成が示唆される。
この効果を定量化するため、潜在平均の温度微分を計算する：

$$\frac{d \langle z_i \rangle_T}{dT}$$

絶対値の大きな勾配は、その潜在座標が温度変化に対して高感度であることを示し、
多くの場合、構造転移付近でピークを持つ。

これにより、潜在トレンドの定性的な観察を定量的な転移感度指標に変換できる。

### 手法

各選択潜在次元に対して：

1. 温度ビン分割された潜在平均を計算する
2. 中心差分微分を適用する
3. |d⟨z⟩/dT| が最大となる温度を特定する

以下を報告する：

- 温度に対する勾配曲線
- ピーク勾配の大きさ
- 各潜在次元のピーク温度推定値

## 解釈

上位ランクの潜在次元は推定臨界温度付近で顕著な勾配ピークを示す。

これは以下を示唆する：

- 転移付近での急速な潜在再編成
- 物理的に整合した座標での感度上昇
- 複数の潜在軸に渡る一貫した転移エンコーディング

対照的に：

- AE / VAE は弱くノイジーな勾配構造を示す。
- ベースラインのコントラスト学習は部分的な感度を示す。
- ヘリシティ認識モデルはよりシャープで一貫したピークを示す。

ピーク勾配温度は以下と密接に一致する：

- ヘリシティモジュラスからの Tc 推定値
- ボルテックスの急速な増殖領域

これはヘリシティ認識学習が
物理的に意味のある潜在構造を安定化するという仮説を支持する。

### エンジニアリングの観点

この解析が示すもの：

- 潜在幾何は微分感度で評価できる。
- 目的関数の設計が転移のシャープさに直接影響する。
- 転移検出は離散分類ではなく
  連続感度問題として定式化できる。

これはコントロールパラメータに渡る
表現の堅牢性に対する定量的評価パイプラインを提供する。

### 重要な定量的洞察

ヘリシティ認識表現は相を分離するだけでなく、
臨界領域付近で最大の微分感度を示す。
これは偶発的なクラスタリングではなく、
構造化された相エンコーディングを示唆する。

```python
    dy = np.zeros_like(y, dtype=np.float64)

    dy[-1] = (y[-1] - y[-2]) / (T[-1] - T[-2])

    return dy
```

## 7. 推定 Tc との比較

### 推定転移温度との比較

モンテカルロシミュレーションと理論的考察から：

$$T_c \approx 0.917$$

勾配感度解析より：

- Y 関連潜在次元のピーク：**T ≈ 0.88–0.90**
- nv 関連潜在次元のピーク：**T ≈ 1.02–1.08**

この非対称性は物理的に意味がある。

ヘリシティ関連量（Y）は $T_c$ の**直前**で不安定になり、
転移前の剛性軟化を反映する。

ボルテックス密度（nv）は $T_c$ の**直後**により急激に増加し、
転移後のトポロジカル欠陥の増殖を反映する。

したがって学習表現は、
臨界領域の両側から転移感度構造を捉えている。

単に相をクラスタリングするのではなく、
モデルは物理的に解釈可能な転移ダイナミクスをエンコードしている。

重要なことに、ピーク位置は学習中に課されたものではなく、
ヘリシティ認識目的関数の設計から自然に出現する。


## 8. クラスター条件付き相関関数解析

### 目的

潜在空間クラスタリングが物理的に異なる領域に対応することを検証する
（単なる幾何学的分離ではないことを確認する）。

各クラスターに対してスピン相関関数を計算する：

$$G(r) = \langle \cos(\theta_i - \theta_{i+r}) \rangle$$

そして温度に渡る減衰挙動を解析する。

### なぜ重要か

2D XY モデルは以下を示す：

- 準長距離秩序相でのべき乗則減衰
- 無秩序相での指数関数的減衰

クラスタリングが物理的に意味があれば、
各クラスターは異なる減衰挙動を示すはずである。

### 実装設計

相関解析はローカルでフルモンテカルロデータに対して行う：

- 入力：
  - クラスターラベル（`*_cluster_vs_T.npz`）
  - MC スピン配置

- 出力：
  - クラスター条件付き平均 $G(r)$
  - log–log および半対数プロット

これにより重いMC計算と可視化が分離され、
再現性を保ちながらリポジトリサイズを抑えられる。

![クラスター条件付き G(r) T=0.80, 1.00, 1.20](results/notebook_data/cluster_cond_G_r_T080_T100_T120.png)

## 解釈
### 🔹 T = 0.80（低温相）

- log–log スケールでほぼ線形
- 半対数スケールで曲線

→ **べき乗則減衰** を示す
→ KT 準長距離秩序相の特徴

クラスター 0 と 2 はともに低温領域に属するが、
わずかに異なる減衰指数を示す。

### 🔹 T = 1.00（転移付近）

- 一つのクラスターが著しく速い減衰を示す
- 他は比較的遅い減衰を維持する

→ **中間構造** の存在を示唆
→ UMAP で観察された「中間層」と一致

これは潜在クラスターが転移物理を捉えているという考えを支持する。

### 🔹 T = 1.20（高温相）

- 半対数スケールで線形
- log–log スケールで曲線

→ **指数関数的減衰** を示す
→ 短い相関長を持つ無秩序相

高温クラスターは明確に短距離相関のみを示す。

## 潜在クラスタリングの物理的検証

潜在空間クラスタリングは単なる幾何学的なものではない。

各クラスターは以下に対応する：

- 異なる相関減衰挙動
- 異なる物理的秩序領域
- 相依存の構造組織

これにより、学習表現が温度ラベリングを超えた
物理的に意味のある構造を捉えることが確認される。

重要なことに、クラスタリングは相関関数へのアクセスなしに行われたが、
物理的に一貫した減衰挙動を回復する。
